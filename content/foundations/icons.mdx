# Иконки

Набор иконок описан в `data/icons.json`. На [портале](/#icons) они показываются в таблице с именем, slug и ссылками в Figma / Storybook.

## Поля в данных

| Поле | Описание |
| ---- | -------- |
| `name` | Отображаемое имя |
| `slug` | Идентификатор (латиница, kebab-case) |
| `figmaUrl` | Ссылка на узел в библиотеке Figma |
| `storybookUrl` | Опционально — сторис |
| `previewUrl` | Путь к SVG/PNG под **`public/`**, например `/portal-icons/arrow.svg` |
| `notes` | Подсказка для команды (где использовать иконку) |

## Текущие slug в каталоге

`arrow-right`, `check`, `close`, `menu`, `search`, `chevron-down`, `plus`, `copy` — см. `data/icons.json`.

## Рекомендации

- Иконки **одного размера** в ряду используйте с единой сеткой и выравниванием по baseline текста.
- Для интерактивных кнопок задавайте **aria-label**, если рядом нет текстовой подписи.
