# Цвета

Семантические цветовые токены используются в интерфейсе для согласованных акцентов, текста, границ и состояний. Ниже — актуальный список из `data/colors.json` (портал подтягивает те же данные).

## Палитра

| Токен | HEX | Назначение |
| ----- | --- | ---------- |
| `color.primary` | `#2563eb` | Основной акцент |
| `color.surface` | `#fafafa` | Фон карточек (light) |
| `color.danger` | `#dc2626` | Ошибка / деструктивное действие |
| `color.success` | `#16a34a` | Успех |
| `color.warning` | `#ca8a04` | Предупреждение |
| `color.info` | `#0ea5e9` | Информация, подсказки |
| `color.text.primary` | `#18181b` | Основной текст |
| `color.text.muted` | `#71717a` | Второстепенный текст |
| `color.border` | `#e4e4e7` | Границы |
| `color.focus.ring` | `#3b82f6` | Обводка фокуса `:focus-visible` |
| `color.overlay` | `rgba(0,0,0,0.45)` | Затемнение под модалками |
| `color.brand.muted` | `#dbeafe` | Фон подсветки под primary |

## Использование

1. В продакшен-коде предпочитайте **CSS-переменные** или токены из вашего сборщика темы, а не «сырой» HEX из документации.
2. Для тёмной темы позже можно расширить JSON отдельными значениями или маппингом — текущий набор ориентирован на светлую базу портала.
