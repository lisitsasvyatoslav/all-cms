# Токены и основы

Здесь описаны **семантические токены** и ресурсы, с которыми работает портал дизайн-системы. Фактические значения задаются в JSON и совпадают с тем, что видно на [главной странице портала](/).

## Разделы

- **[Цвета](/docs/foundations/colors)** — палитра и ключи токенов (`color.*`).
- **[Иконки](/docs/foundations/icons)** — набор иконок, превью из `public/`, ссылки в Figma.

## Источники правды

| Что | Где в репозитории |
| --- | ---------------- |
| Цвета | `data/colors.json` |
| Иконки | `data/icons.json` |
| Компоненты (карточки на портале) | `data/components/*.json` |

При изменении токенов обновите соответствующий JSON и при необходимости этот раздел документации.
