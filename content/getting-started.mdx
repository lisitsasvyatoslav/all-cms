# Быстрый старт

## Два слоя контента

| Слой | Папка | Назначение |
| ---- | ----- | ---------- |
| **Документация** | `content/` | MDX-страницы под префиксом **`/docs`** (то, что вы читаете сейчас). |
| **Витрина** | `data/` | JSON для портала: `components/*.json`, `colors.json`, `icons.json`, `portal-sources.json`. |

## Локальный запуск

```bash
npm run dev
```

- **Документация (Nextra):** [http://localhost:3000/docs](http://localhost:3000/docs)
- **Портал с карточками:** [http://localhost:3000/](http://localhost:3000/)

## Структура документации

В сайдбаре слева:

- **Введение** и этот раздел.
- **Основы** — обзор токенов, [цвета](/docs/foundations/colors), [иконки](/docs/foundations/icons).
- **Компоненты** — [обзор](/docs/components) и страницы Button, Card, Badge и др.

Новые MDX-файлы добавляйте в `content/`; оглавление настраивается через **`_meta.js`** рядом с файлами.

## Полезные файлы

- `data/portal-sources.json` — ссылки на Figma, Storybook, репозиторий (блок «Источники» на портале).
- `lib/content/load.ts` — как Next читает JSON в приложении.
