# Text Field

Поле ввода **однострочного текста** в формах.

## Рекомендации

- Связывайте `<label>` с полем по `id` / `htmlFor`.
- Показывайте ошибки валидации текстом рядом с полем, не только цветом.
- Для паролей и многострочного ввода используйте отдельные паттерны (password field, textarea).
