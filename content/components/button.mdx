# Button

Кнопка для **основных и второстепенных действий** в формах, модалках и тулбарах.

## Назначение

Используйте Button для действий с немедленным эффектом («Сохранить», «Отмена», «Далее»). Текст кнопки должен явно описывать результат.

## Поведение и доступность

- Явный тип: `button` в формах, если отправка не нужна по умолчанию.
- Для иконки без текста задайте **`aria-label`**.
- Состояния: disabled, loading — блокируйте повторные клики при отправке.

## Данные и витрина

Описание и ссылки в **`data/components/button.json`**, интерактивная карточка: [/components/button](/components/button).
