# Компоненты

Библиотека UI-компонентов описана в JSON (`data/components/*.json`). На **портале** для каждого компонента есть страница с описанием и ссылками — перейдите по slug из таблицы ниже.

## Каталог

| Компонент | Док портала | Файл данных |
| --------- | ----------- | ----------- |
| Button | [/components/button](/components/button) | `button.json` |
| Card | [/components/card](/components/card) | `card.json` |
| Badge | [/components/badge](/components/badge) | `badge.json` |
| Dialog | [/components/dialog](/components/dialog) | `dialog.json` |
| Select | [/components/select](/components/select) | `select.json` |
| Switch | [/components/switch](/components/switch) | `switch.json` |
| Text Field | [/components/text-field](/components/text-field) | `text-field.json` |

## Документация в этом разделе

Для каждого компонента добавлена отдельная страница с назначением, рекомендациями по доступности и ссылками на Figma / Storybook (как в данных). Детали правьте в MDX в `content/components/` и при необходимости синхронизируйте с JSON.
