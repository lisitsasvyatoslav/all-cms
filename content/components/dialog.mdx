# Dialog

**Модальное окно**: фокус внутри диалога, закрытие по Esc и клику по оверлею, корректная семантика для скринридеров (`role="dialog"`, `aria-modal="true"`).

## Когда показывать

- Подтверждение деструктивного действия.
- Форма, которую нельзя смешивать с основным потоком страницы.

## Доступность

- Перенос фокуса при открытии и возврат при закрытии.
- Явная кнопка закрытия и понятный заголовок.
