# Select

**Выпадающий список** для выбора одного значения из набора.

## Когда использовать

- Выбор из длинного списка фиксированных опций.
- Для поиска по списку и произвольного ввода рассмотрите Combobox отдельно.

## Поведение

- Клавиатура: стрелки, Enter, Escape.
- На мобильных учитывайте нативные паттерны, если используете обёртку.
