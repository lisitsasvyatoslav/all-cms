# Switch

**Переключатель вкл/выкл** с немедленным эффектом (в отличие от группы checkbox в фильтрах).

## Когда использовать

- Включение функций, уведомлений, режимов.
- Не заменяет выбор из нескольких вариантов — для этого radio или select.

## Доступность

Связывайте переключатель с подписью через `aria-labelledby` / видимый label.
