# Дизайн-система

Здесь собраны **гайды и спецификации** для команды: токены (цвета, иконки), описание UI-компонентов и ссылки на витрину.

## С чего начать

1. **[Быстрый старт](/docs/getting-started)** — где лежат файлы (`content/`, `data/`) и как открыть портал.
2. **[Токены и основы](/docs/foundations)** — цветовые токены и иконки из JSON.
3. **[Компоненты](/docs/components)** — обзор и отдельные страницы по каждому паттерну.

## Витрина компонентов

Интерактивные карточки с данными из репозитория доступны на **[главной странице портала](/)** — разделы компонентов, цветов и иконок слева в навигации.

## Редактирование

| Раздел | Папка |
| ------ | ----- |
| Эта документация (MDX) | `content/` |
| Данные витрины (JSON) | `data/` |

После правок перезапуск dev-сервера обычно не нужен — страницы подхватят изменения автоматически.
