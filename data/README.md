# Контент портала (JSON)

Папка **`data/`** читается Next-порталом через `lib/content/load.ts`.

| Файл / папка | Назначение |
|--------------|------------|
| `portal-sources.json` | Общие ссылки |
| `components/*.json` | По одному файлу на компонент (`slug` → `/components/[slug]` в Next) |
| `colors.json` | Массив токенов цветов |
| `icons.json` | Массив иконок; `previewUrl` — путь из `public/` |

Документация в формате MDX лежит отдельно в **`content/`** и открывается по префиксу **`/docs`** (Nextra).

После правок сохраните файл и обновите страницу Next.
